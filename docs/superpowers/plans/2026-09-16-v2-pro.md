# XSMB V2 PRO Implementation Plan

Goal: Upgrade the supplied desktop source into a local responsive dashboard, retaining the V1.3 ledger database.
Architecture: Python loopback HTTP server, static HTML/CSS/JS dashboard; SQLite repository; NumPy feature and optimization engine; openpyxl/ReportLab exports. All operations stay local except explicit result downloads.
Scope: implement the user's modules; no guaranteed predictive performance; no fabricated real data; no automatic staking.

## 1. Analytics and evaluation
- Test: 30 feature columns, complete 00–99 ranking, deterministic output; no future input in walk-forward evaluation.
- Implement src/pro_analytics.py: build_features(draws, target), rank(draws, weights), pairs and deterministic k-means clustering.
- Implement src/pro_backtest.py: simulate with hits counted by multiplicity, explicit per-number points, cost/payout, ROI, profit/loss days and gaps skipped. Daily records are the chart source.
- Implement src/optimizer.py: fixed seed candidate weights; train/validation/test chronological partitions; select on train, report validation and untouched test; save model only for future dashboard ranking.

## 2. Storage and actual finance
- Test: V1.3 data remains accessible; immutable forecast snapshots; same-day/future data never settle a prior forecast before it exists; daily/week/month/year aggregation agrees with ledger totals.
- Implement src/pro_service.py: dashboard snapshots, journal, settings, capital summaries; use existing ledger.py.
- Keep simulated journal cash separate from actual entries.

## 3. Data and exports
- Test: CSV exact 27 outcomes per draw, date validation, duplicate-date rejection, atomic writes; fallback skips wrong-day or incomplete HTML.
- Implement src/pro_data.py: named adapters (Dai Phat, Minh Ngoc, XSKT, KQXS), strict validation, bounded timeouts, fallback and provider logs.
- Implement src/reports.py: CSV, XLSX and PDF using same selected dataset and decimal VND; embed Vietnamese font; include units and methodology.

## 4. Dashboard and server
- Implement src/pro_server.py with loopback binding, session token for API access, Host/Origin validation, request limits, one background job with status polling, cancellation and shutdown.
- Implement web/index.html, app.css, app.js: sidebar, 8 modules, cards, 00–99 heatmap, confidence gauge, tables, theme toggle, Canvas pan/zoom charts, forms and reports.
- Change launcher and PyInstaller spec to bundle web and font assets; Windows scripts install runtime dependencies.

## 5. Verification and delivery
- Run pytest, syntax checks, HTTP tests, export readers and browser rendering if available.
- Package without personal database, demo data or build caches.
- Include exact test results and unverified Windows/source limitations in README; persist updated ZIP.
